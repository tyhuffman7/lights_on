PM-US uses `GET /v1/order/{id}`, `GET /v1/orders/open`, portfolio activities and private execution streaming; cancellation is `POST /v1/order/{id}/cancel`. Cancellation is not evidence of zero fills and is not invoked by this checkpoint. Bounded FOK requests should leave nothing resting; any contradictory resting state halts for review.
